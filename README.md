### <div align="center"><p>🚀 Как запустить 🚀</p></div>

<hr>

### 👨‍💻 Для `.py`:

  1. Установите **Python 3.13** c [официального сайта](https://www.python.org/) ([3.13.9](https://www.python.org/downloads/release/python-3139/))
  2. Скачайте `MeowTool.py` и `requirements.txt`
  3. В папке, где находится `requirements.txt`, в строке пути введите `cmd` и нажмите `Enter`
     ![Enter cmd in search line](https://github.com/user-attachments/assets/7f7761ed-86b5-4ddf-9431-923b1434e5dd)
  4. В открывшейся консоли введите `pip install -r requirements.txt`
  5. После установки всех зависимостей запустите `MeowTool.py`

### 💿 Для `.exe`:

  1. Перейдите в [релизные версии](https://github.com/h1kken/MeowTool/releases)
  2. Выберите нужную версию и скачайте `MeowTool.exe`
  3. Запустите `MeowTool.exe`

### <div align="center"><p>💡 Полезная информация 💡</p></div>

<hr>

### 🌐 Прокси
  - Поддерживаемые протоколы: `IPv4` | `http` / `https` / `socks4` / `socks5`
  - Поддерживаемые форматы:
    - `protocol://user:pass@ip:port`
    - `protocol://ip:port:user:pass`
    - `protocol://ip:port`
  - Во всех функциях, где происходит работа с куки роблокс есть поддержка прокси

### 🗺️ Навигация
  - При перемещении по меню символы можно вписывать по разному, например, чтобы перейти в настройки, можно использовать такие символы: `S`, `s`, `Ы`, `ы`

### ⌨️ Горячие клавиши
  - `R` перезагрузит текущий конфиг, полезно при изменении настроек через файл
  - `F` починит консоль, если текст отображён некорректно

### ✍️ Добавление своих бейджей и геймпассов в куки чекер
  1. Перейдите по пути: `Настройки > Конфиги`
  2. Включите `Авто. сохранение изменений`, если не включено
  3. Перейдите в: `Настройки > Роблокс > Куки Чекер > Кастомные плейсы`
  4. Добавьте туда любой плейс, содержащий желательно и бейджи и геймпассы, например, `Adopt Me (920587237)`
  5. Теперь, перейдём в наш конфиг, он находится по пути: `..\Settings\Configs`
  6. Спуститесь... в самый низ, до `[Roblox.CookieChecker.CustomPlaces]`
  7. Там увидите вот такие данные:\
     ![Data in config](https://github.com/user-attachments/assets/f6b1598f-465d-4282-9c09-0a3185a24747)
  8. Айди `920587237` можно заменить любым другим числом, хоть `777`. Главное, чтобы оно находилось в `List_Of_Custom_Places` и "папки" для плейса имели соответствующие названия: `777`, `777_Gamepasses` и `777_Badges`\
     ![Highlighted data in config](https://github.com/user-attachments/assets/d2636e87-5a2d-4ece-ae48-9983dcf005bf)
  9. Бейджи и геймпассы имеют вид `[Айди, Название, Проверять?]`. Вы можете удалить сгенерированное и добавить своё
  10. В итоге, получаем вот такую картину:\
      ![MeowTool Custom Places](https://github.com/user-attachments/assets/b1c61835-dfae-43a9-889c-c44f31496605)

### <div align="center"><p>🚀 Как запустить 🚀</p></div>

<hr>

### 👨‍💻 Для `.py`:

  1. Установите **Python 3.13** c [официального сайта](https://www.python.org/) ([3.13.9](https://www.python.org/downloads/release/python-3139/))
  2. Скачайте `MeowTool.py` и `requirements.txt`
  3. В папке, где находится `requirements.txt`, в строке пути введите `cmd` и нажмите `Enter`
     ![Enter cmd in search line](https://github.com/user-attachments/assets/7f7761ed-86b5-4ddf-9431-923b1434e5dd)
  4. В открывшейся консоли введите `pip install -r requirements.txt`
  5. После установки всех зависимостей запустите `MeowTool.py`

### 💾 Для `.exe`:

  1. Перейдите в [релизные версии](https://github.com/h1kken/MeowTool/releases)
  2. Выберите нужную версию и скачайте `MeowTool.exe`
  3. Запустите `MeowTool.exe`

### <div align="center"><p>🛠️ Возможности 🛠️</p></div>

<hr>

  - **🌐 Proxy Checker ✅**: проверит прокси на работоспособность

  - **🍪 Roblox Cookie Checker ✅**: проверит куки на выбранные данные

    - 🔎 Проверка данных: `Country Registration`, `ID`, `Name`, `Display Name`, `Registration Date (D.M.Y)`, `Registration Date (In Days)`, `Robux`, `Billing`, `Pending`, `Donate (1 Year)`, `Donate (All Time)`, `Rap`, `Card`, `Premium`, `Gamepasses`, `Custom Gamepasses`, `Badges`, `Favorite Places`, `Places Weekly Playtime`, `Bundles`, `Inventory Privacy`, `Trade Privacy`, `Can Trade`, `Sessions`, `Email`, `Phone`, `2FA`, `Pin`, `Groups Owned`, `Groups Members`, `Groups Pending`, `Groups Funds`, `Place Visits`, `Age Group`, `Verified Age`, `Verified Voice`, `Friends`, `Followers`, `Followings`, `Roblox Badges`, `X-CSRF-Token`
  
    - 🗂️ Сортировка данных: `Country Registration`, `ID`, `Name`, `Display Name`, `Registration Date (D.M.Y)`, `Registration Date (In Days)`, `Robux`, `Billing`, `Pending`, `Donate (1 Year)`, `Donate (All Time)`, `Rap`, `Card`, `Premium`, `Gamepasses`, `Custom Gamepasses`, `Badges`, `Favorite Places`, `Places Weekly Playtime`, `Bundles`, `Inventory Privacy`, `Trade Privacy`, `Can Trade`, `Sessions`, `Email`, `Phone`, `2FA`, `Pin`, `Groups Owned`, `Groups Members`, `Groups Pending`, `Groups Funds`, `Place Visits`, `Age Group`, `Verified Age`, `Verified Voice`, `Friends`, `Followers`, `Followings`, `Roblox Badges`
    
      - Каждая категория может иметь несколько возможностей сортировки, но вот список всевозможных:
        
        - Сортировать числа от `...`
        - Сортировать числа от `...` до `...`
        - Сортировать `нуль`
        - Сортировать по названию `бейджа` / `геймпасса` / `бандла` / `плейса` / `группы`

  - **🍪 Roblox Cookie Sorter 🗂️**: собирает все куки из `.txt` файлов в один
    - Проходит по всем директориям кроме главной папки `outputs`, где хранятся результаты

  - **🍪 Roblox Cookie Refresher 🔄**: обновит куки аккаунтов
    - Одиночный режим
    - Массовый режим

  - **🍪 Transaction Analysis 📊**: проверяет транзакции в выбранных плейсах

  - **🔎 Парсеры 📑**: больше полезно для разработчиков своих чекеров
    - Бейджи
    - Геймпассы

### <div align="center"><p>💡 Полезная информация 💡</p></div>

<hr>

### 🌐 Прокси
  - Во всех функциях, где происходит работа с куки роблокс есть поддержка прокси

### 🗺️ Навигация
  - При перемещении по меню символы можно вписывать по разному, например, чтобы перейти в настройки, можно использовать такие символы: `S`, `s`, `Ы`, `ы`

### ⌨️ Горячие клавиши
  - `R` перезагрузит текущий конфиг, полезно при изменении настроек через файл
  - `F` починит консоль, если текст отображён некорректно

### ✍️ Добавление своих бейджей и геймпассов в куки чекер
  1. Перейдите по пути: `Настройки > Конфиги`
  2. Включите `Авто. сохранение изменений`, если не включено
  3. Перейдите в: `Настройки > Роблокс > Куки Чекер > Кастомные плейсы`
  4. Добавьте туда любой плейс, содержащий желательно и бейджи и геймпассы, например, `Adopt Me (920587237)`
  5. Теперь, перейдём в наш конфиг, он находится по пути: `..\Settings\Configs`
  6. Спуститесь... в самый низ, до `[Roblox.CookieChecker.CustomPlaces]`
  7. Там увидите вот такие данные:\
     ![Data in config](https://github.com/user-attachments/assets/f6b1598f-465d-4282-9c09-0a3185a24747)
  9. Айди `920587237` можно заменить любым другим числом, хоть `777`. Главное, чтобы оно находилось в `List_Of_Custom_Places` и "папки" для плейса имели соответствующие названия: `777`, `777_Gamepasses` и `777_Badges`\
     ![Highlighted data in config](https://github.com/user-attachments/assets/d2636e87-5a2d-4ece-ae48-9983dcf005bf)
  11. Бейджи и геймпассы имеют вид `[Айди, Название, Проверять?]`. Вы можете удалить сгенерированное и добавить своё
  12. В итоге, получаем вот такую картину:\
      ![MeowTool Custom Places](https://github.com/user-attachments/assets/b1c61835-dfae-43a9-889c-c44f31496605)

  - Добавлен анализ транзакций
  - Переименование: Куки парсер -> Куки сортер
### Настройки -> Роблокс -> Анализ транзакций -> Общее

  - Добавлен переключатель использования SSL
  - Добавлен переключатель сохранения всех плейсов в один файл
  - Добавлен переключатель сохранения плейсов по разным файлам

  - Добавлен переключатель сохранения робуксов после плейсов в названиях файлов
  - Добавлен переключатель выбора отступа в общем файле со всеми плейсами
### Настройки -> Роблокс -> Анализ транзакций -> Прокси
  - Добавлен переключатель использования прокси
  - Добавлен выбор протокола, если он явно не указан в файле

       - Добавлен переключатель счёта игнорируемых транзакций в общей сложности

  - Переименование: Purchases -> Donate (All Time)
  - Теперь сортировка каждой категории выполняется в 1 момент, а не очередью
  - Исправлена сортировка данных, выключенных в чекере, но включенных в сортировке, которые нужны для получения других данных
### Роблокс -> Куки сортер
  - Сортер ускорен в ~17 раз
### Роблокс -> Куки рефрешер
  - Исправлено некорректное отображение времени до следующего рефреша
### Роблокс -> Куки чекер и Куки сортер
  - Исправлено появление пустых папок, если куки не найдены
### Роблокс -> Куки чекер и Анализ транзакций
  - Добавлен переключатель показа количества строк в файлах
### Роблокс -> Куки чекер, Куки сортер, Куки рефрешер (Массовый режим) и Анализ транзакций
  - Добавлен переключатель воспроизведения звука по завершении работы
### Настройки -> Роблокс -> Куки чекер -> Общее
  - Добавлен переключатель использования SSL
  - Добавлен переключатель именования выходного файла так же, как входного
  - Добавлено изменение названия выходного файла
